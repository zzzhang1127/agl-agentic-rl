# Critic独立评估进展（2026-10-16）

当前已验证修复后的任务终止与评分接口，正在采集独立留出轨迹。**尚无完整留出集
质量结论，actor保持禁用；历史step200仅作存在终止语义污染风险的诊断对照。**

## 已完成的集成验证

两个固定烟测任务分别真实走通compaction后继续build、主任务stop、结构化评分，
以及同一批准轨迹上的初始化critic和step200 critic推理。一次得到有效零奖励，
另一次得到有效正奖励；每轮只有一个批准样本，目标方差为零，因此EV不可定义。
这两轮不拼接成独立质量报告，也不作为打开actor的依据。

首轮发现外层600秒总时限包含排队和启动，会在runner运行约576秒时撤销任务。
后续外层改为1260秒，runner执行和评分仍各600秒，生成预算不变。未真正结束的
任务即使测试结果有数值，也不能成为有效训练或评估奖励；超时单列，不填零。

## 固定留出集与比较方法

固定64题通过salted hash从615题留出桶选择，覆盖34个仓库。题目ID及规范化prompt
与19份历史critic训练文件不重叠，ID也与VAL474不重叠；不按奖励或参考patch筛题。
镜像与执行协议预检支持其中62题；其余2题明确记录缺失镜像，其中1题另有Go协议
不支持。完整报告必须保留64题分母、62题执行覆盖和每项失败原因。

62题按原顺序偶/奇索引分成互不重叠的31题两组，四卡同时评估。每组保持已验证
的两rankcritic原生加载方式，共享只读checkpoint，不复制或另存模型。每组最多
两题并发，四小时有界运行，并检查实际写入盘空间。全部产物位于数据盘项目目录。

共享GPU上的第二组曾在vLLM0.8.5初始化时失败：其显存profile把同卡其他进程的
非Torch占用也算入peak，低util参数导致估算缓存余量为负。核对安装源码后，
仅该组调整profile预算参数，保留显式1024个KV blocks；实际缓存和生成预算未增加。
重试已越过引擎初始化并发出真实模型请求，失败尝试保留、不纳入结果。

只对批准轨迹比较固定seed42初始化critic、step200，以及预先定义的常数0/0.5。
报告token MSE、按轨迹平均MSE、起始value误差、汇总EV、校准及正负覆盖。
两分片完成后合并全部原始预测重新计算指标，不能简单平均分片EV或挑成功样本。
更新和模型保存RPC在评估进程中被阻断。

## 解释边界

- 少量训练batch的正EV、loss下降或单题成功均不证明泛化。
- runner超时、基础设施失败、上下文超限等单列，不当成模型负样本。
- 终止门禁修复不消除旧step200的训练污染风险，详见
  [历史训练结论纠正](critic-final-20261016.md)。
- 正负覆盖、相对基线误差和稳定EV等最终指标尚待完整评估，不自动开启actor。

已发布代码的回归证据沿用[终止修复记录](critic-terminal-20261016.md)；本次更新为
有真实运行证据的实验进展文档，不声明新增代码测试或完整评估已经通过。
