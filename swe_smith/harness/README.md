# SWE-smith 评测工具导航

## 一次评测的组成

1. `smith_fleet.sh`：配置 vLLM 推理实例；先审查 GPU、端口与模型路径。
2. `run_smith_sweep.py` / `smith_rollout.py`：执行任务并记录逐题结果。
3. `accuracy_smith.py`：汇总评测读数。
4. `paired_cmp.py`：在对照与实验的共同题目上做 McNemar 配对比较。
5. `eta_smith.py`：估算运行进度。

脚本保留历史环境与输出格式假设，需配置外部模型和任务镜像；本目录不是
自带完整数据与模型的评测服务。

## 比较前必须核对

- 相同题集、模型起点、harness/template、40或100轮预算、采样参数及超时。
- 两次运行是否完成全部预期题目，基础设施失败和缺失题目如何处理。
- `paired_cmp.py` 当前对题目ID的**交集**计算配对值；它不会自动证明两组
  都完成了474题。必须先核对各自题数、交集与缺失清单，不能把不完整交集
  当成全量验证结果。
- 报告总体正确数与分母，同时保留新做对/丢掉的配对计数。模型自选的
  “已提交子集”会改变分母，不能替代全量比较。

历史结果集中于 [结果页](../../docs/results.md)，实验背景见
[SWE-smith说明](../README.md)。
